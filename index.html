C#WinFormsFactoryInterfacesPDF

App Expedientes

⚡ Redujo un proceso de 1.5–3 horas a 3 minutos

Aplicación de escritorio desarrollada en C# WinForms para automatizar el armado de archivos de facturación para clientes farmacéuticos. Cada cliente exige un formato distinto para procesar los pagos — esta herramienta lo resuelve con un solo clic.

El sistema procesa archivos descargados del sistema Ralpharma y los convierte automáticamente: dos clientes reciben archivos .txt con formato específico, y un tercer cliente requiere un QR por factura exportado en PDF, listo para imprimir.

Incluye una herramienta de edición masiva de campos para corregir errores rápidamente, sin necesidad de editar archivo por archivo.

El mayor desafío fue el tiempo: la herramienta debía estar lista y funcionando antes del mediodía para no interrumpir la operación del negocio.

Patrones aplicados: Factory, Interfaces, Herencia, Polimorfismo.

App Expedientes Web

En desarrollo

Evolución de la App Expedientes original hacia una arquitectura web moderna. El código fue reescrito desde cero con un enfoque más robusto y profesional, utilizando ASP.NET Core y arquitectura de APIs REST.

El principal desafío es la migración conceptual: repensar una aplicación de escritorio en términos de servicios, endpoints y DTOs, manteniendo toda la lógica de negocio intacta pero adaptada al entorno web.

Tecnologías: .NET, ASP.NET Core, REST APIs, DTOs, Interfaces, Herencia, Polimorfismo.

Sistema Arcade en C#

Simulación de un juego de carnaval desarrollada íntegramente en C#, sin motor gráfico. Fue el proyecto donde apliqué herencia y aprendí sobre interfaces por primera vez.

Un-Ghost

Prototipo experimental de un juego en primera persona. El jugador tiene dos armas: una que atrae fantasmas y otra que les hace daño. El objetivo es derribar a los fantasmas que salen de un portal y encerrarlos en frascos distribuidos por el mapa.

Es el proyecto donde más patrones de diseño implementé simultáneamente: Flyweight para optimización de memoria, Abstract Factory para creación de entidades, Observer para comunicación entre sistemas y Command para las acciones del jugador. También fue el primer proyecto donde implementé shaders personalizados.

Ekeko

Roguelike 2.5D inspirado en la cultura latinoamericana. El mundo es 3D pero todos los assets son 2D — una combinación visual compleja inspirada en Cult of the Lamb.

El jugador encarna a un Ekeko y recorre dungeons eligiendo cartas al inicio de cada run, cada una con una sala especial distinta (8 opciones: tesoro, descanso, espiritualidad y más). El sistema de reliquias y augurios añade profundidad estratégica: acumular reliquias de la misma clase desbloquea sinergias con múltiples niveles de potencia.

Mi rol: desarrollé todos los assets visuales — personajes, decoraciones, pisos, íconos, UI y animaciones. El mayor desafío fue crear sprites 2D que funcionaran coherentemente dentro de un entorno 3D.
